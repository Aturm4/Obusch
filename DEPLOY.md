# Как вывести сайт в интернет (для кента и ученика)

Цель: получить постоянную ссылку вида `https://что-то.onrender.com`, которую кент и ученик
открывают с любого устройства. Делается один раз, минут на 15.

Хостинг — **Render** (есть бесплатный вход, данные хранятся на постоянном диске).

---

## Шаг 1. Залить код на GitHub

Нужен аккаунт на **github.com** (бесплатный). Если его нет — зарегистрируйся.

В папке проекта уже готов git-репозиторий с коммитом. Осталось создать пустой репозиторий
на GitHub и запушить:

1. На github.com нажми **New repository** → имя любое (например `design-club`) → **Private** → **Create**.
2. GitHub покажет адрес репозитория. Выполни в терминале, в папке `c:\obusch`:

```bash
git remote add origin https://github.com/ТВОЙ_ЛОГИН/design-club.git
git branch -M main
git push -u origin main
```

(При пуше GitHub попросит логин и токен — следуй подсказкам, либо войди через GitHub Desktop.)

---

## Шаг 2. Развернуть на Render

1. Зайди на **render.com** → зарегистрируйся (можно через тот же GitHub).
2. **New +** → **Blueprint**.
3. Выбери свой репозиторий `design-club`. Render сам найдёт файл `render.yaml` и предложит
   создать сервис с диском — жми **Apply**.
4. Подожди 2–4 минуты, пока соберётся («Live»). Render даст ссылку вида
   `https://uiux-design-club.onrender.com` — это и есть адрес сайта.

> **Про тарифы.** В `render.yaml` стоит план `starter` (~$7/мес) — он нужен, чтобы данные
> (аккаунты, ДЗ, переписка) **не терялись**. Если хочешь сначала бесплатно потестить —
> в `render.yaml` поменяй `plan: starter` на `plan: free` и удали блок `disk`. Но на free
> данные сбрасываются при перезапуске сервиса — для реального обучения бери `starter`.

---

## Шаг 3. Создать аккаунты (важно — по порядку!)

Открой выданную ссылку. На сайте — экран входа, внизу **«Зарегистрироваться»**.

1. **Сначала регистрируется КЕНТ** (наставник):
   - роль: **Наставник**
   - код приглашения: значение `MENTOR_INVITE_TOKEN` из Environment сервиса Render (Blueprint генерирует его; у существующего сервиса добавьте случайное приватное значение вручную)
   - имя, e-mail, пароль
   - → он автоматически становится наставником потока.

Код не публикуйте в репозитории и передавайте только доверенному наставнику. Для закрытия новых регистраций наставников удалите переменную; существующие аккаунты продолжат входить.
2. **Потом регистрируется УЧЕНИК**:
   - роль: **Студент**
   - → автоматически прикрепляется к наставнику.

Всё. Можно вести занятия:
- ученик смотрит уроки, отправляет ДЗ файлом, ведёт чек-лист;
- наставник видит ученика в «Обзоре», проверяет работы в «Очереди» (ставит оценки и вердикт),
  ведёт «Конструктор курса» (модули / уроки / домашки);
- оба переписываются в «Чате» в реальном времени.

---

## Если что-то пошло не так

- **«Application failed to respond» / 502** сразу после деплоя — подожди минуту, идёт запуск.
- **Сбросились данные** — значит сервис на плане `free`. Переключи на `starter` с диском (Шаг 2).
- **Забыли пароль** — пока сброса пароля нет; создайте новый аккаунт или напишите мне, добавлю.
- **Поменяли код и хотите обновить сайт** — просто `git push`, Render передеплоит сам.

## Запасной вариант без хостинга (на сегодня/потест)

Если нужно прямо сейчас и без GitHub/Render — можно запустить у себя на ПК и открыть
публичный туннель (cloudflared). Скажи мне — настрою за пару минут. Минус: работает только
пока твой компьютер включён.
